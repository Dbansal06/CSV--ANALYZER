# 📈 CSV Analyzer

**CSV Analyzer** is a beginner-friendly Streamlit web application that allows users to upload and analyze multiple CSV datasets with ease. It offers interactive data cleaning, visualization, and basic machine learning modeling — all from a user-friendly UI.

---

## ✅ Features

- 📤 Upload multiple CSV files or load from a public URL (e.g., Kaggle, GitHub).
- 📊 Merge and analyze datasets interactively.
- 🧼 Handle missing data (Drop, Fill with Mean, Fill with Median).
- 📈 Visualizations:
  - Scatter plots
  - Correlation heatmaps
- 🧠 Build simple prediction models (Linear, Ridge, Lasso Regression).
- 🌐 Multilingual support (English and Hindi).
- 🌙 Toggle between Light and Dark themes.
- ⬇️ Download cleaned data as CSV.
- 📉 Font size auto-adjusts for large datasets to avoid messy charts.

---

## 🚀 Installation

1. **Clone the repository**:
   ```bash
    git clone [https://github.com/Dbansal06/CSV--ANALYZER.git](https://github.com/Dbansal06/CSV--ANALYZER.git)
    ```
2.  **Navigate into the project directory:**
    ```bash
    cd CSV--ANALYZER
    ```
    *(Note: If your operating system is case-sensitive or if you want to be precise, use the exact casing as the folder name.)*

3.  **[Optional, but recommended] Create and activate a virtual environment:**
    ```bash
    python -m venv .venv
    # On Windows:
    .venv\Scripts\activate
    # On macOS/Linux:
    source .venv/bin/activate
    ```

4.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
